# 🥷 ArashiRun

> A fast-paced 2D Ninja Runner Game built using HTML, CSS, and JavaScript.

---

## 🎮 About The Game

**ArashiRun** is an endless runner game where the ninja runs forward automatically.  
The player must jump over monsters, collect coins, and survive as long as possible.

✨ Smooth animations  
💰 Coin collection system  
👹 Monster obstacles  
❤️ Life system  
🎵 Background music
